## ⚠️ 已知坑位（防止再踩）

### 坑位 1: `marked` 导入方式（已踩）
- **错误**: `const { marked } = require('marked')` → marked v18 解构得到 `undefined`
- **正确**: `const marked = require('marked')`
- **原理**: marked 模块导出 `{ parse, setOptions, use, Marked }`，没有 `marked` 属性

### 坑位 2: `preload.js` 顶层异常静默失败
- **现象**: `preload.js` 报错时 Electron 不弹窗，`window.echora` = `undefined`
- **后果**: 所有功能（菜单、Agent 加载）全部失效，难以调试
- **预防**: `preload.js` 顶层代码用 `try/catch` 包裹，异常时 `console.error` 并暴露最小可用桥接

### 坑位 3: `renderer.js` 单文件过大（64KB）
- **现状**: 备份版本 ~58KB，经过 Sprint 5 改动后膨胀到 ~64KB
- **风险**: 人工编辑容易引入语法错误（少括号、重复函数定义）
- **建议**: 拆分为 `renderer-core.js` / `renderer-chat.js` / `renderer-agents.js` / `renderer-settings.js`，通过 `index.html` 多 `<script>` 加载

### 坑位 4: 两个 `escHtml()` 函数定义
- **位置**: `renderer.js` 第 908 行和第 1053 行
- **风险**: 后定义覆盖前定义，行为不一致
- **修复**: 保留一个，另一个删掉（建议保留第 908 行版本，支持多类型输入）

### 坑位 5: `handleGatewayStatusAll` 中变量名错误
- **位置**: `renderer.js` 第 142 行
- **错误**: `statuses` 参数被误写为 `statuses[ai.id]` 但循环变量是 `statuses`
- **实际**: 需要对比备份确认（备份版本应该是正确的）

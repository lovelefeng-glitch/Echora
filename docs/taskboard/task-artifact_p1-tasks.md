## 二、任务 1：思考过程显示增强

### 2.1 当前状态

- ✅ 有 `thinking` 状态（`StreamPhase`）
- ✅ 有 `ThinkingInfo` 类型定义
- ✅ 有基本的状态显示（左边框颜色变化）
- ❌ 没有显示思考内容文本
- ❌ 没有可展开/折叠的思考面板

### 2.2 目标效果

```
┌─────────────────────────────────────┐
│ 🤖 AI 回复                         │
├─────────────────────────────────────┤
│ ▶ 💭 思考过程 (点击展开)           │  ← 可折叠
│   正在分析用户问题...               │  ← 思考内容
│                                     │
│ 这是 AI 的回复内容...              │
└─────────────────────────────────────┘
```

### 2.3 实现步骤

#### Phase 1: 思考内容显示
1. 修改 `ChatMessageItem.tsx`
2. 添加思考内容折叠/展开状态
3. 显示 `streamStatus` 作为思考文本

#### Phase 2: 思考面板样式
1. 添加思考面板 CSS 样式
2. 使用 CSS 变量保持主题一致

## 三、任务 2：文件浏览器

### 3.1 目标效果

```
┌─────────────────────────────────────┐
│ 🛠️ 工具面板            [🔄] [✕]  │
├─────────────────────────────────────┤
│ [🌐 网页] [📄 代码] [📁 文件] [💻] │  ← 新增文件按钮
├─────────────────────────────────────┤
│ 📁 src/                            │
│   📁 renderer/                     │
│     📄 App.tsx                     │  ← 点击预览
│     📄 stores/                     │
│   📁 main/                         │
│ 📁 docs/                           │
└─────────────────────────────────────┘
```

### 3.2 实现步骤

#### Phase 1: 文件树组件
1. 创建 `FileExplorer.tsx` 组件
2. 实现文件树渲染（递归组件）
3. 添加展开/折叠功能

#### Phase 2: 文件预览联动
1. 点击文件 → 调用 `showPreview` 显示代码
2. 支持文件类型检测和语法高亮

#### Phase 3: IPC 通道
1. 添加 `file:read` IPC 通道
2. 主进程实现文件读取

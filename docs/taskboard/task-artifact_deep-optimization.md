## 一、功能深度分析

### 1.1 文件浏览器（深度优化）

#### 当前问题
- ❌ 模拟数据，不是真实文件系统
- ❌ 没有搜索功能
- ❌ 没有最近打开文件
- ❌ 点击文件只是模拟预览

#### 优化目标

```
┌─────────────────────────────────────┐
│ 📁 文件浏览器           [🔍] [🔄] │
├─────────────────────────────────────┤
│ 🔍 搜索文件...                      │
├─────────────────────────────────────┤
│ ⭐ 最近打开                          │
│   📄 App.tsx                        │
│   📄 app-store.ts                   │

│   📁 renderer/                      │
│     📄 App.tsx          ← 点击预览  │
│     📁 components/                  │
│   📁 main/                          │
│ 📁 docs/                            │
└─────────────────────────────────────┘
```

#### 实现步骤

| 步骤 | 内容 | 依赖 |
|------|------|------|
| 1.1 | IPC 通道：`file:list`, `file:read`, `file:search` | 主进程 |

| 1.4 | 最近打开文件列表 | localStorage |

## 二、执行计划

### Phase 1: IPC 通道（基础设施）
**时间**: 1-2 小时

1. 主进程添加文件系统 IPC
   - `file:list` - 列出目录
   - `file:read` - 读取文件
   - `file:search` - 搜索文件

2. Preload 暴露 API
   - `window.echora.file.list()`
   - `window.echora.file.read()`
   - `window.echora.file.search()`

### Phase 2: 文件浏览器深度优化
**时间**: 2-3 小时

1. FileExplorer 组件重写
2. 搜索功能
3. 最近打开文件
4. 点击预览联动

### Phase 3: 终端深度优化
**时间**: 2-3 小时

1. 实时日志流接入
2. 日志级别过滤
3. 搜索功能
4. 清空/导出

### Phase 4: 思考过程深度优化
**时间**: 1-2 小时

1. thinking 事件接入
2. ThinkingBlock 多步展示
3. 时间戳和折叠

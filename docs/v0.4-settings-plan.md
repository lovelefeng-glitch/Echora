# Echora 系统设置开发方案

**版本**: v0.4.0-target
**日期**: 2026-05-19
**状态**: 规划中

---

## 1. 需求概述

用户希望能：
1. **调整超时时间** — 全局 + 按 AI 类型独立覆盖
2. **注册 AI 配置文件路径** — 手动添加 JSON 配置路径（QClaw/OpenClaw 等）
3. **读取配置（只读）** — 解析并展示各 AI 软件配置内容（agents、models 等）
4. **为模型切换铺路** — OpenClaw 有多达 11 个 model provider，后期可切换

## 3. 架构设计

### 3.1 配置结构扩展

```json
{
  "settings": {
    "autoStartOnBoot": false,
    "minimizeToTray": true,
    "checkUpdates": true,
    "timeout": 120000,                    // 全局超时(ms)
    "timeoutPerAI": {                     // 按 AI 类型覆盖
      "qclaw": 120000,
      "openclaw": 180000
    },
    "pollInterval": 10000                 // 状态轮询间隔(ms)
  },
  "aiConfigPaths": {                      // 新增：AI 配置文件路径
    "qclaw": "C:\\Users\\ohfen\\.qclaw\\openclaw.json",
    "openclaw": "C:\\Users\\ohfen\\.openclaw\\openclaw.json"
  }
}
```

### 3.2 新增模块：`src/manager/config-reader.js`

```javascript
const ConfigReader = {
  // 读取并解析 AI 配置文件
  read(filePath) → { success, data, error }
  
  // 自动发现已知路径
  discover() → { qclaw: path|null, openclaw: path|null }
  
  // 规范化提取（屏蔽敏感字段）
  normalize(aiType, rawData) → {
    agents: [{id, name, model}],
    models: [{provider, models: [id,...]}],
    port: number,
    ...
  }
};
```

### 3.3 新增 IPC 通道

| 通道 | 方向 | 功能 |
|------|------|------|
| `ai-config:set-path` | renderer→main | 注册 AI 配置路径 |
| `ai-config:read` | renderer→main | 读取指定 AI 配置文件（返回规范化数据） |
| `ai-config:discover` | renderer→main | 自动发现已知路径 |
| `ai-config:list` | renderer→main | 列出所有已注册路径及读取状态 |
| `settings:get` | renderer→main | 读取单个设置项（与 config:get 同） |
| `settings:set` | renderer→main | 写入单个设置项 |

### 3.4 renderer.js 超时接入

```javascript
// 原来的硬编码
const safetyTimer = setTimeout(..., 120000);

// 改为
const settings = STATE.settings || await window.echora.settings.getAll();
const timeout = settings.timeoutPerAI?.[agent.aiType] || settings.timeout || 120000;
const safetyTimer = setTimeout(..., timeout);
```
